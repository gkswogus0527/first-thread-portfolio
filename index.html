나의 작업으로 채우는 법

  1. 내 작업 편집을 켜고 기획안 카드를 수정하거나 새 작업을 추가하세요. 커버 이미지와 외부 작업물 링크도 넣을 수 있습니다.
  2. 소개·연락처에서 한 줄, 나의 이야기, 공개용 이메일을 바꾸세요. 이메일은 선택 사항입니다.
  3. HTML 내보내기를 누르면 현재 내용과 커버 이미지가 들어간 홈페이지 파일이 다운로드됩니다. 원본과 별도로 저장해두세요.
  4. 그 파일을 다시 열거나 정적 웹 호스팅에 index.html로 올릴 수 있습니다. 이 파일을 만든 것만으로 공개 배포되지는 않습니다.

로그인·서버·분석 추적을 사용하지 않습니다. 임시 저장은 브라우저·파일 경로별로 동작이 다를 수 있어 내보내기를 권장합니다. 편집 버튼은 소유자 인증이 아니며 방문자도 자기 브라우저에서 수정할 수 있지만 원본 사이트를 바꾸지는 못합니다. 연락처와 작업 링크는 직접 추가하기 전 연결되지 않습니다. 커버 그림은 홈페이지용 일러스트이며 실제 작업 화면이 아닙니다.
